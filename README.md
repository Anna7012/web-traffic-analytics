# Web Traffic Analytics

## Project Overview
This project analyzes website traffic data using Microsoft Excel to understand traffic patterns over time.

## Tools Used
- Microsoft Excel
- GitHub

## Dataset
The dataset contains two columns:
- Timestamp
- TrafficCount

## Analysis Performed
- Total website traffic
- Average traffic
- Maximum traffic
- Minimum traffic
- Traffic trends over time

## Visualization
Created a line chart to visualize website traffic trends over time.

## Objective
To understand website traffic patterns and identify periods of high and low traffic.

## Conclusion
This project demonstrates basic website traffic analysis and data visualization using Microsoft Excel.
